# 所得税汇缴报告复核规则

> 对应模板年度：2025 年度申报表（模版）。模板随每年新规更新，坐标可能变——**跨年时先用"行次/项目名定位法"重新确认坐标，再更新本文件，不要改代码**。

## 产出物构成

| 文件 | 角色 |
|---|---|
| `00企业所得税报告（含说明）.docx` | 审核报告正文 + 附件1 审核事项说明（330 段、3 张内嵌表） |
| `20XX年度企业所得税申报表.xlsx` | 50 sheets 全套申报表 + 5 套会计准则财务报表，全公式联动 |

## Excel 申报表结构

### 驱动层
- `基本信息`（辅助表，不打印）：红色单元格据实填报，驱动全簿单位名/年度/准则。必填检查点：D6 单位名称、D7 纳税人识别号、D8 法定代表人、D13 所属年度、D15 会计准则（脚本 REQUIRED_CELLS 常量）。
- `封面`：全部公式引用基本信息，无需检查内容，只需确认公式未被覆盖。
- `企业所得税年度纳税申报表填报表单`：C 列人工勾选"√"，D 列公式自动反勾。勾选一致性检查的对照源。

### 申报表层（官方表号 sheet）
`A000000基础信息表` → `A100000主表` ← 各明细表。主表列布局：B=行次、D=项目、E=金额。

关键勾稽链（行次为 2025 模版）：
- 主表 E4 营业收入 ← `A101010一般企业收入明细表!C4`（金融企业则 A101020）
- 主表 E5 营业成本 ← `A102010一般企业成本支出明细表!C4`
- 主表 E7-E9 期间费用 ← `A104000期间费用明细表` 第 30 行对应列
- 主表 纳税调整 ← `A105000纳税调整项目明细表`（C账载/D税收/E调增/F调减）← A105010~A105120 各专项调整表
- 主表 弥补亏损 ← `A106000弥补亏损明细表`
- 主表 优惠 ← `A107010免税减计收入及加计扣除` ← A107011/A107012 等；`A107040减免所得税优惠` ← A107041（高新）/A107042（软件）
- 汇总纳税企业：`A109000`/`A109010` ← 主表应纳所得税额行

### 财报层（自动对账）
5 套准则财务报表（已执行/未执行/小企业/会计制度/民非）。`利润表（已执行）` E 列是**差异校验列**（如 `E6=B6-A100000主表!E4`），差异应=0；≠0 即财报与申报表不一致，报 error。

## 报告文字 ↔ 申报表 标准勾稽点（link_map 来源）

在 Step 2 按下表逐项建立 link_map 条目。text_hint 是报告段落关键词；坐标需先按行次/项目名核对。

| id | 报告位置（text_hint） | 申报表位置 | 说明 |
|---|---|---|---|
| 利润总额 | 正文"利润总额为 X 元"（或附件说明表格 table#0"1. 利润总额"行） | A100000 主表 利润总额行（按 D 列项目名"利润总额"定位所在行 E 列） | 报告数=主表数 |
| 应纳税所得额 | 正文/说明"应纳税所得额" | A100000 应纳税所得额行 | 同上 |
| 应纳所得税额 | 同上 | A100000 应纳所得税额行 | 同上 |
| 应补（退）税额 | 正文"应补（退）" | A100000 应补（退）所得税额行 | 同上 |
| 纳税调增合计 | 说明中纳税调整段 | A105000 调增合计行（E 列） | |
| 纳税调减合计 | 同上 | A105000 调减合计行（F 列） | |
| 加计扣除额 | 说明中研发费段（如有） | A107012 加计扣除合计 | 与加计报告交叉 |
| 分支机构分摊 | 说明 table#2（分支机构名称/分摊系数/已交税款/应补退税款） | A109010 对应行 | 仅汇总纳税企业 |

**行次/项目名定位法**：在 sheets.json 的 A100000 sheet 里找 D 列值为"利润总额"（可能带行次前缀如"19．利润总额"）的行，取同行 E 列坐标。不要硬背行号。

## 完整性检查点

1. 填报表单勾选 ↔ 附表实填一致（勾了没填=warning，填了没勾=info）
2. 财报差异列（利润表 E 列、资产负债表勾稽行）全为 0
3. 基本信息必填项非空
4. A000000 基础信息表：企业类型/汇总纳税标志与主表 A109000 是否启用一致
5. 报告正文文号（如"中会税所[2026]第000号"）、报告日期、签章页完整

## 文本格式检查点

- 公司名全称在报告正文、说明、申报表封面三处一致
- 所属年度在文号、正文、封面、A000000 各处一致
- 常见错别字（"应纳税所得额"误作"应纳税所得税额"等），通读 report_text.md 用语义判断
- 模板占位符未替换：XXXX、XXX公司、△△、脳脳（乱码占位）、"[请根据…" 提示语残留 → error

## 易误判点（终审注意）

- 报告正文"利润总额为 0.00 元"模板示例值与未填模板一致——未填模板做模板完好性检查时，数字勾稽无意义，focus 在公式健康
- 金融企业/事业单位用 A101020/A103000 替代 A101010，link 前先看 A000000 企业类型
- "小型微利企业"减免在 A107040 直接引用主表，不需要企业填数
- 纳税调整明细表存在合法的账载≠税收差异（这正是调整表的意义），不要把 A105000 内部 C≠D 当错误
