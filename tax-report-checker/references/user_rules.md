# 用户自定义规则

用户在对话中描述的特殊检查需求，整理后写入下方"## 我的规则"。规则跟着 skill 走（不绑定具体报告目录），所有报告共用。检查时一并执行。规则失效或需修改时，用户在对话里说即可，更新本文件。

格式：自然语言描述 + 适用场景 + 期望结果。
