# 研发费用加计扣除报告复核规则

> 对应模板：研发费加计扣除报告（2024 版附件）。附件有**两种样式**：2015 样式 与 2021及自行设计样式，结构相同（26 sheets），按 A000000/A107012 中的样式勾选判断企业用哪版。

## 产出物构成

| 文件 | 角色 |
|---|---|
| `01研发费加计扣除报告.docx` | 审核报告正文 + 附件1 审核事项说明（90 段、2 张内嵌表） |
| `02研发费加计扣除报告附件XXXX版-XXXX样式.xlsx` | 26 sheets 全公式联动工作簿 |

## Excel 附件结构（数据流）

```
未审到审定提供数据-基于数电   （RD01~RD20 项目列 × 科目行，E 列=行合计 SUM(F:Y)）
        ↓
数据中转（A107012 口径重组）
        ↓
┌─ 附件3项目一~项目二十（每项目归集表，4列，D列引用数据中转对应列）
└─ 数据汇总（992 公式，汇总全部项目）
        ↓
附件2优惠明细表（汇总，A107012 口径，D列=合计）
无形资产摊销台账（独立 sheet，27 公式）
```

## 报告文字 ↔ 附件 标准勾稽点

| id | 报告位置（text_hint） | 附件位置 | 说明 |
|---|---|---|---|
| 账面归集研发费 | 审核意见段"账面归集研发费用发生额X元" | 附件2优惠明细表 账面归集行（或数据汇总对应行） | |
| 审核可加计研发费 | 审核意见段"实际可用于计算加计扣除的研发费用X元" | 附件2优惠明细表 审核后研发费合计 | 核心数 |
| 加计扣除总额 | 审核意见段"加计扣除总额X元" | 附件2优惠明细表 加计扣除合计行（=可加计研发费×比例） | 比例现行 100% |
| 核减合计 | 说明"共计核减X元，核定X元" | 数据中转/附件2 核减列 | |
| 委托研发 | 说明"委托研发费用"段 | 附件2 委托研发行（80% 计入） | 财税〔2018〕64号 |
| 其他相关费用限额 | 说明"其他相关费用"段 | 附件2 其他相关费用限额行（10% 限额公式 `SUM-...-...*20%` 类） | 限额调整后 |
| 项目数量 | 说明"研发项目共XX项" | 附件2 G7（COUNTIF 项目数） | |
| 资本化金额 | 说明"本年资本化金额X元" | 无形资产摊销台账对应行 | |

附件2 内每行 D 列=合计公式（如 `D8=ROUND(D9+D13+D22+D25+D29+D40,2)`），check_values 会自动双重校验。

## 内嵌表检查

- table#0：研发项目清单（编号/名称/计划周期/预算）——与附件中实际有数的项目数、项目名称一致
- table#1：费用明细汇总（序号/费用明细/金额）——金额与附件2 对应行一致

## 完整性检查点

1. 有数据的 RD 项目列 ↔ 项目N sheet 实际启用（项目表 D 列引用非空）
2. 附件2 纳税人名称/识别号 = 报告正文公司名 = Sheet1 参数
3. 报告文号、出具日期、税务师签章完整
4. 加计比例表述与现行政策一致（2023 年第 7 号公告起 100%；模板说明段会引用文号，核对文号正确）

## 易误判点

- 报告模板含大量"（以下没有核减的条目删除）""（如采用该条，以下可删）"等**编辑提示语**——成品报告中这些应已删除，残留 → error"模板提示语残留"
- "贵公司本年度无委托研发情况。（如采用该条，以下可删）"这类二选一段落，成品中应只保留适用的一种
- 2015 样式与 2021 样式的差异只在归集口径，勾稽点相同，坐标相同（两版同构）
- 未填模板金额为 0/空属正常，模板完好性模式下 focus 公式健康
